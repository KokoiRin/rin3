# 忠实、易读的中文翻译

## 核心目标

让读者轻松读懂原文，同时保留原文全部信息和逻辑。表达与格式都是实现这个目标的手段，不要求套用固定句式、版式或教学流程。

## 不可改变的边界

- **内容完整。** 保留正文、例子、代码、公式、图表、注释、脚注、练习和引用；不能因重复、进阶或难懂而删减。
- **含义一致。** 保留主语、对象、条件、例外、否定、程度、因果和时序。例如，“可能”不能变成“一定”，“只有……才……”不能变成“只要……就……”。
- **原文与补充分明。** 保持章节、段落及论证顺序，不用自己的教学提纲替换原文。新增解释或类比只在用户需要时提供，并明确标注；发现原文疑点也另作说明，不静默改写结论。

## 怎样让阅读更轻松

在原段落内按中文习惯组织句子：拆开长句，说清谁在什么情况下做什么，让指代和前后关系容易辨认。用自然、平实的口吻，不靠删减、夸张比喻或堆砌语气词降低阅读难度。

保留更容易识别的英文专业术语，首次出现时按需简释，同篇用法一致；代码标识符保持原样。普通词语用自然中文。标题可以改得直白，但含义、范围和层级不变。

已有用户认可的译文时，以它为表达尺度。需要把握改写程度时，参考[表达示例](references/translation-style.md)。排版以清楚、连续、便于对照为准，不为满足模板增加控件、批注或学习记录。

## 怎样确认做好了

先逐段对照原文，确认信息没有增删、关系和限定没有改变；再单独通读中文，检查是否顺畅、是否需要反复回读才能理解。只有译文可供核对时，如实说明范围。

代码、公式、图片和链接等内容单独核对。已有完整性检查可以辅助验证，但元素数量一致不能证明语义一致。
