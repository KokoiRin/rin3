# 阅读器排版

仅在制作或调整网页阅读器时使用。排版服务于阅读；已有用户认可的页面优先沿用，不为统一外观重新设计。

## 延续现有阅读体验

- 同一系列沿用字体、正文宽度、行距、标题层级和导航。保持单栏连续阅读，不默认增加侧栏或分类工具栏。
- 新页面可从[阅读器模板](../assets/reader-shell.html)开始，按内容取舍模板中的可选部分，不为填满模板编写额外内容。
- 复用共享样式；为特殊图表添加局部样式，不改动整套阅读节奏。

## 图表与公式

- 文字润色保留现有图片、公式、代码、链接目标和定位标识；标题改名时同步目录文字，保留锚点。
- 需要翻译图中文字时，可保留原图配译文，或忠实重绘。重绘须保留实体、关系、方向和阶段；自行归纳的图另行标注。
- 沿用 `.figure-frame` 图框与图注，提供有意义的 `alt`，或 `role="img"` 与 `aria-label`。
- 复杂公式使用项目已有 KaTeX 在生成时渲染，放入 `.math-display`；旧公式资源继续兼容。

## 页面可用性

- 小屏幕上正文保持易读，宽表格、代码、图和公式允许横向滚动，不撑宽整页。
- 使用系统中文字体和本地资源，不依赖远程字体或运行时接口。章节位于 `public/reading/<book>/<chapter>/index.html` 时，共享样式通常使用 `../../reader.css`。
- 保留来源、章节导航和返回入口。相对链接须适配本地打开与站点路径前缀；独立本地版本需带齐样式等资源。
- 打印时隐藏操作控件与装饰，尽量避免图和标题跨页断裂。

页面有展示变化时检查桌面、小屏幕和相关打印效果；文字润色不必重做排版验收。
