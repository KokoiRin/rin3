# 书籍学习页画图与图片验收指南

这份指南用于 RIN III 的书籍翻译和学习页。目标不是把图画得“像原书”，而是在不改变原意的前提下，让读者更快看懂正文正在表达的关系。

默认使用项目已有能力：

- HTML/CSS：简单卡片、对照框和文字布局；
- SVG：需要精确控制对象、箭头、颜色和响应式的正式图示；
- Mermaid：只有当内容天然是流程、时序或状态关系，而且默认布局已经足够清楚时才使用。

不要为了画图引入新的在线工具或运行时。现有能力无法清楚表达时，再单独评估其他方案。

## 一、画图指导

### 1. 先写一句话图意

动手前先写出读者看图后应该说出的那句话。例如：

> 服务不能直接接触对方内部状态；同步请求和异步消息都要经过双方的公共接口。

如果这句话还写不清楚，就先不要画。图中的每个框、箭头和颜色都应该服务于这句话。

### 2. 只保留必要语义

先列出：

- 对象：图里有哪些主体；
- 边界：哪些内容属于同一个范围；
- 关系：对象之间是调用、依赖、包含、转换还是时间先后；
- 方向：信息从哪里来、到哪里去；
- 重点：正文希望读者注意哪一个关系。

没有承担语义的装饰、图标和箭头应删除。不要让读者猜测两种相似符号是否表示不同含义。

### 3. 先保证层级，再考虑美观

视觉面积和强调程度应与概念重要性一致：

- 主体比接口、标签和装饰更稳定；
- 边界要能看出“里面”和“外面”；
- 核心关系位于视觉中心，不能缩成角落里的小符号；
- 同级对象使用一致的大小、样式和对齐；
- 强调色只用于需要读者优先注意的部分。

不要出现接口比服务主体更抢眼、箭头比对象更粗重、大片空白吞掉核心关系等情况。

### 4. 文字必须正常阅读

- 中文默认横排；除非竖排本身有明确语义，否则不要使用竖排文字；
- 不允许单字被动换行、裁切、重叠或依赖极小字号；
- 图中术语与正文保持一致；
- 箭头含义不能只靠颜色区分，应配合文字或线型；
- 正式图使用项目正文相近的中文字体栈。

### 5. 桌面和手机可以使用不同构图

宽图在手机端直接缩小，往往会让文字变得不可读。优先采用：

- 桌面：横向展开关系；
- 手机：改为纵向排列，关系方向随布局旋转；
- HTML 使用 `<picture>` 或媒体查询选择对应 SVG；
- 两种构图必须表达同一句图意，不能因为响应式而改变语义。

### 6. 保留可维护的源文件

- 正式图优先保存 SVG，而不是只保留 PNG 截图；
- SVG 使用 `viewBox`，由容器控制宽度；
- 文字保留为文字，不要全部转成路径；
- 文件名能够对应章节和图号；
- 图片必须提供准确的 `alt`，描述图意而不是重复“图 14-1”。

## 二、图片验收标准

图片是否通过，采用“硬门禁 + 0—4 分评分”。平均分不能掩盖致命问题。

### 1. 四道硬门禁

| 门禁 | 必须满足 |
| --- | --- |
| 语义正确 | 对象、边界、关系和箭头不改变原文含义 |
| 阅读无阻塞 | 无异常断字、裁切、重叠、不可辨识的小字和关键歧义 |
| 响应式可用 | 桌面和手机都能看清，并表达相同图意 |
| 可访问 | 有准确替代文本；不能只靠颜色传达关键信息 |

任一道失败，图片直接不通过，无需计算平均分。

### 2. 0—4 分锚点

| 分数 | 可观察含义 |
| --- | --- |
| 0 | 缺失或错误，会建立错误理解 |
| 1 | 内容存在，但明显妨碍理解 |
| 2 | 可以猜懂，需要反复阅读正文或外部解释 |
| 3 | 能够独立、稳定地看懂 |
| 4 | 看懂后能够准确复述，并迁移到类似场景 |

### 3. 七项评分

逐项评分并记录证据：

1. 一句话图意：5 秒内能否说出图要表达什么；
2. 对象与层级：主体、边界、接口和附属元素是否主次明确；
3. 关系与方向：每条线和箭头是否有唯一、清楚的含义；
4. 文字可读性：字号、换行和术语是否稳定；
5. 空间与重心：空白是否帮助分组，重点是否位于视觉中心；
6. 原文忠实度：重画是否保持原书的事实和关系；
7. 响应式表现：桌面与手机是否同样易懂。

通过条件：

- 四道硬门禁全部通过；
- 七项平均分不低于 3；
- “一句话图意”“关系与方向”“原文忠实度”都不低于 3；
- 任意一项出现 0，直接不通过；关键图任意一项为 1，也不通过。

### 4. 必须保留的证据

每张关键图至少留下：

- 桌面截图或渲染结果；
- 390px 左右的手机渲染结果；
- 页面横向溢出检查；
- SVG 文字溢出、节点重叠或等价人工检查；
- 一次 5 秒图意测试的结果；
- 失败项和修改后的复测结果。

自动检查只能证明图“没有坏”。是否真正易懂，仍要由未参与绘图的人或独立评审完成 5 秒图意测试。
