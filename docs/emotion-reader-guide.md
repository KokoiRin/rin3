# 情绪阅读页内容与视觉规范

这份规范用于 `public/reading/emotions/` 下的五天情绪阅读页与后续选读图鉴。第 2 天是视觉基线；第 1、3～5 天和选读页必须复用共享样式，只在内容需要时增加新结构。

RIN 只保留一个系列级入口：`content/me/emotion-awareness-five-day.md`。五天完整阅读页和选读图鉴仍各自存在，但不再为每页创建独立的内容条目；所有阅读页都返回系列总入口。

## 一、学习目标

每页只完成一件事：帮助读者用情境、关注点和行动倾向区分当天的三种情绪。页面不是诊断、治疗、性格测试或私人经历采集工具。

完成标准不是“读完很多知识”，而是读者能够：

1. 用自己的话说出三种情绪各自在评价什么；
2. 对至少一组近邻概念说出判断线索；
3. 在新情境里先判断，再说明依据；
4. 允许混合情绪，并为每一种情绪指出不同对象。

## 二、固定内容顺序

除非主题确实不适用，每天保持以下顺序：

1. **Hero**：一句核心判断、三个锚点、阅读时间与数据边界；
2. **闭卷回忆**：用三个新情境召回前一天概念；
3. **五天地图**：标出当前位置，不制造进度焦虑；
4. **直觉判断**：三个情境、0～6 即时评分、折叠辨析；
5. **三种情绪正文**：定义、关注点、内在语言、行动倾向、跨场景例子、核心问题、近邻对比、三联画；
6. **一分钟比较**：三条问题和行动方向；
7. **案例图谱**：每种情绪至少覆盖六个生活领域；
8. **概念边界**：至少三组容易混淆的对照；
9. **混合情境**：同一事件中拆出三个不同评价对象；
10. **六道检索题**：先判断，再展开理由；
11. **迁移方法**：不填写、不保存，可在现实中默念；
12. **有效性边界**：可以期待、不必期待、一个检验；
13. **三句带走**与**研究来源**。

## 三、写作约束

- 先写情境，再写情绪词；少用抽象定义堆叠。
- 每种情绪必须写清“关注点”和“行动倾向”，不能只描述身体感觉。
- 示例覆盖工作、关系、身体、公共环境、选择和日常生活，不把一种情绪绑在单一场景。
- 近邻辨析使用“更接近”“通常突出”“可能并存”，不宣称唯一标准答案。
- 不把情绪等同于事实、责任或道德判决。例如“感到内疚”不自动证明本人应负责。
- 不诱导用户披露私人经历；评分只在内存中存在，刷新即清空。
- 每页明确声明：材料不用于诊断或治疗。
- 研究结论优先使用原始研究、同行评审综述和稳定的情绪概念资料；页面末尾保留来源与适用边界。

### 选读图鉴的完整结构

`public/reading/emotions/explore/` 下的页面不是训练日，不显示 Day 编号、五天地图或连续打卡；但内容密度不得低于第 2～4 天。每页至少包含：

1. 一个值得辨析的中心问题；
2. 三个不靠关键词作答的直觉情境；
3. 一张事件优先的比较三联画；
4. 三种情绪各自完整的定义、评价对象、内在语言与行动倾向；
5. 每种情绪一张专属三联画和至少六个跨领域案例；
6. 一分钟比较与覆盖十八个以上场景的案例图谱；
7. 至少三组容易混淆的概念边界；
8. 一个允许三种情绪并存的混合情境；
9. 六道包含反例或相邻概念的检索题；
10. 可迁移到真实生活的三步判断方法；
11. 有效性边界、三句带走与研究来源。

选读页明确写出“不是第六天”，不制造继续打卡或必须完成的压力；“自由选读”只改变进度关系，不允许成为减少材料、案例或视觉质量的理由。

## 四、视觉系统

共享资源：

- `public/reading/emotions/shared/reader.css`
- `public/reading/emotions/shared/rating.js`

视觉基线：

- 暖纸色背景、深墨色正文、珊瑚色强调；不增加渐变、玻璃效果或大面积高饱和色。
- 大标题使用中文宋体栈，正文使用系统无衬线字体。
- 依靠排版、留白、细分隔线和整块底色建立层级；默认无阴影、无悬浮卡片感、少用圆角。
- 桌面最大宽度 1440px；主要正文约 1100px；手机在 620px 以下收为单栏并隐藏长导航。
- 新页面不得复制并私改一份 CSS。确需新增组件时，先判断能否服务后续页面，再更新共享样式。

## 五、三联画约束

五天主线和选读页中，每种情绪都使用一张 1536×1024 的横向三联画。选读页可以额外使用一张比较三联画作为开场概览，但不能用它替代三种情绪各自的专属图片。每一格都必须依靠事件结构而不是人物表情完成辨析：

- 三个等宽竖向场景，窄暖白分隔；
- 平面编辑插画：深青色硬轮廓、大块平涂、简化人物与五官，只保留轻微纸张颗粒和少量排线；避免水彩晕染、写实光影、摄影景深及精细皮肤或织物纹理；
- 暖象牙、低饱和蓝绿、灰蓝与少量珊瑚；
- 使用不同生活领域和多样成年人物；
- 采用远景或中远景，以事件、物件、空间关系、前因后果和行动表达情绪；人物表情只能作为弱辅助，禁止用面部近景或夸张表情替代事件叙事；
- 新图必须把第 2 天至少一张原始三联画作为显式风格与构图参考；验收时同时比较轮廓、平涂方式、镜头距离和“事件先于表情”四项，不得只比较色调；
- 不含文字、标志、水印、对话框或装饰性图表；
- 图下注明三格各自表达的领域与判断线索。

图片验收同时遵循 `docs/reading-illustration-guide.md`：桌面和约 390px 手机均可读，`alt` 描述图意，5 秒内能说出三格的共同情绪结构。

- [ ] 六道检索题没有只靠关键词猜答案；
- [ ] 即时评分不写入存储，也不上传；
- [ ] 每页三张专属图片均为 1536×1024；选读页如含比较图则共四张，文件名、`alt` 和图注一致；
- [ ] 不读人物表情也能在 5 秒内说清每一格发生了什么；
- [ ] 复用共享 CSS 与评分脚本；
- [ ] 桌面 1280px 和手机 390px 无横向溢出；
- [ ] 内容契约、公开安全检查和生产构建通过；
- [ ] 页面入口与完整阅读页都能打开。
- [ ] RIN 中只有一个系列入口，五个完整阅读页和全部选读页都返回该入口。
