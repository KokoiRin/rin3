从会写 Kotlin，走到看懂 Android 怎样运行它

这不是 Android API 百科。它先把系统入口、页面实例、状态、返回路径、线程、View 与状态所有权连成一条可以解释、可以画出、可以落到真实项目的链路。

建议每章 45～70 分钟

  1. 先看“用户可观察链路”，把系统行为和用户动作连起来。
  2. 正文只读一节就停一次，自己画图或预测下一步回调。
  3. 代码必须独立敲，练习答案先折叠；最后用真实项目做迁移。
  4. 四类完成证据都留下后再进入下一章，不用追求一次记牢全部 API。

01Android 应用是怎么运行起来的没有唯一 main() 时，系统怎样通过组件进入你的进程和页面。 02项目结构、Manifest 与资源一份源码如何被组织、声明、打包，并匹配到设备资源。 03Activity 与生命周期首次进入、切后台、返回与旋转分别怎样改变页面实例。 04配置变化、进程死亡与状态恢复把 UI 临时状态、恢复事实和持久业务数据放到正确位置。 05Intent、Task 与返回栈解释 A → B → C、Back、Home 与应用图标背后的实例变化。 06主线程、Looper、MessageQueue 与 Handler弄清任务怎样排队、执行，为什么长任务会卡住所有 UI。 07View 树、事件分发与绘制一根手指和一个布局请求怎样穿过父子树，得到最终画面。 08ViewModel、UI State 与状态所有权建立状态向下、事件向上的闭环，并分清 ViewModel 的边界。

这套课刻意没有讲什么

不会在这里展开 Compose 编译原理、完整启动模式组合、协程结构化并发、网络、Repository、Room、性能专项或 Framework native poll。它们都有后续课程；本阶段的目标是先获得不会塌的 Android 应用模型。

课程依据 Android Developers 官方文档重新组织，最后核对：2026-08-24。它是个人学习用的非官方中文桥接课，不声称逐段翻译；遇到版本差异时，以各章链接的官方原文为准。
