一天读了书，或者这一天休息

上一篇用记录描述“一条数据同时具有哪些项目”。现在遇到另一种需求：一天的事件可能是读了一本书、记录页数，也可能是休息。读书时需要书名和页数；休息时没有这两项，不能靠一本空书名和一个特殊数字让大家猜含义。

我们希望输入“读 SML 这本书 12 页”时得到页数 12，输入“休息”时得到 0。ML 可以先用 datatype 列出允许的几种形状，再用 case 根据形状挑选处理办法。| 分隔不同情况，=> 左边描述要认出的形状，右边写相应计算。

下面的完整例子先建立两种事件，再实现取页数的函数。Read 给数据加上“阅读事件”的标记，RestDay 本身就是不携带数据的休息事件。

第一次调用收到 Read ("SML",12)，选中第一条分支，并让 title 对应 "SML"、pages 对应 12，右边便返回 12。第二次收到 RestDay，选中另一条分支，返回 0。这里的 0 是明确规定“休息日计入多少页”的结果，不是在用 0 冒充“未知事件”。

datatype 一次建立了什么

原课用一个故意没有实际用途的例子，把不同情况展示得更完整。mytype 的值可以携带一对整数、一个字符串，或者不携带数据：

这条 datatype 定义引入新的类型名 mytype，还引入三个构造器：TwoInts、Str、Pizza。构造器负责建立带有相应标记的数据。名字由程序员选择，大写开头是原课沿用的习惯，不是说只能使用这些英文词。

写法 类型与含义
TwoInts int * int -> mytype，接收整数对后构造值
Str string -> mytype，接收字符串后构造值
Pizza 已是一个 mytype 值，没有要接收的数据

因此 a 得到 Str "hi"；b 却是函数值 Str 本身，不是已经构造好的 mytype。漏写构造器所需的数据不一定导致类型错误，也可能得到一个仍在等待输入的函数。c 则可以直接是 Pizza，它不需要再写 Pizza ()。

计算 d 时，先把 1+2、3+4 算成 3、7，再构造 TwoInts (3,7)。e=a 仍遵循第一周的规则：查询已经得到的值，所以 e 也是 Str "hi"。标记没有消失，Str "hi" 不是裸字符串，TwoInts (3,7) 也不是裸整数对。

case 把“认形状”和“取内容”放在一起

面对 mytype，我们需要先知道是哪个构造器建立的值，再使用它携带的数据。ML 没有自动生成 isStr、getStrData 等检查与取值函数，而是让 case 一次完成这两件事。下面沿用刚才的 mytype 定义，是视频及课堂代码中的函数版本。

f (TwoInts (7,9)) 先取得整个输入值，再从上到下寻找匹配分支。Pizza、Str s 都不匹配，TwoInts (i1,i2) 匹配成功，于是在这条分支中得到 i1=7、i2=9，然后算出 16。没有选择的分支不会执行。

=> 左边叫作模式：它负责检查形状，并给内部数据起局部名字。虽然 TwoInts (i1,i2) 很像构造一个值的表达式，但这里不是调用构造器，更不是先求出 i1、i2；恰好相反，是从已经给定的值中取得它们。名字可以换成 left、right，含义不变，范围只在对应分支右边。

Str s 分支虽然取得了 s，视频版本并没有使用它，仍返回固定的 8。阅读笔记则展示了另一种有意义的处理：用 String.size 取得字符串长度。下面沿用同一个数据类型，给这个版本另起名字，输入 Str "hi" 会得到 2。

分支可以做不同计算，结果类型必须一致

f 的三条分支都返回整数，因此它的类型是 mytype -> int。case 本身也是表达式：整个值就是选中分支得到的值，可以放在 let 的主体、另一个算式、函数实参中，不要求一定占据整个函数体。

类型检查会检查所有分支，要求它们的结果类型一致；不会因为“我本次只传 Pizza”，就放过另一条分支的类型问题。输入也必须符合被匹配的类型，不能省掉标记，把 "hi" 直接当成 Str "hi"。

编译器怎样帮助我们发现漏掉的情况

完整的匹配把允许的几种情况放在一起，检查器便能发现遗漏和冗余。更直接的收益是：在 Str s 分支中，字符串已经安全地交给了 s，不需要再写可能从错误形状取值的操作。这解决的是“形状与取值不一致”的错误，不保证分支里的任意算术或其他函数永远不会失败。

若确实需要检查形状的函数，可以用 case 自己定义，但原课不推荐把平常处理又拆回“先检查、再另行取值”。后面我们也会把第一周的列表与 option 改写成模式匹配，减少检查与读取脱节的机会。

补充：重复声明 datatype，会建立新的类型

datatype 不是给旧类型补一遍同样的文字。重新执行相同声明，会建立新的类型及同名构造器；旧数据仍属于原来的类型，因此旧值与新函数可能不再配合。原视频重新开始会话后加载整份定义，是为了避免这种历史混用，并不是我们刚学的普通整数值突然改变了。
