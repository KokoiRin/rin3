这组材料怎样读

想象一次 assembleDebug 构建：settings 决定包含哪些项目，构建脚本应用插件并声明依赖，插件注册任务，任务将选定 source set 的代码和资源编译、处理、打包。缓存影响其中哪些工作需要重做；KMP 再把这套关系扩展到多个平台。

先读每篇的导读，再读官方正文。编号表示先后关系，不是每天必须完成的份量。第一次先建立概念之间的关系；配置细节可在实际看工程或排查构建时回查。无需先写一个 Gradle 插件。

本组包含 14 篇正文全文与 1 篇明确节选。第 05 篇只选取 Java Library Plugin 文档中讨论 API 与实现依赖的两节，其余内容可沿官方原文继续阅读。每篇都提供英文对照，代码、命令与图中文字保留原样。
