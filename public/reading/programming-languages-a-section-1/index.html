第 3 部分

把计算内部的步骤安排好

保存中间结果，避免重复工作，表达没有记录的情况，再安全地读取答案。

08let 与局部函数：理清内部的步骤先用中间结果完成一次计算，再把只服务当前任务的辅助函数留在内部。对应 V10 / V1109求最高页数：怎样避免反复计算比较当前一天与剩余天数的最大值，看重复求解为何变慢，以及怎样只计算一次。对应 V1210Option：没有记录时，怎样回答从空列表没有最大值这个问题出发，区分“没有答案”与“答案恰好是零”。对应 V1311布尔与比较：先检查，再安全读取沿最大值函数解释有条件的读取，再补齐真假运算、大小比较和数值类型的规则。对应 V14
