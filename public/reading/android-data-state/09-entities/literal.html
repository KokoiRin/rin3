使用 Room 持久化库保存应用数据时，需要定义实体来表示要保存的对象。每个实体对应数据库中的一张表，每个实体实例对应表中的一行。

通过 Room 实体，无须编写 SQL 就能定义数据库结构。

实体的组成

用带 @Entity 标注的类定义实体。实体包含对应表中各列的属性，其中一列或多列构成主键。

下例定义一个 User 表的实体，包含 ID、名字和姓氏列：

@Entity
data class User(
    @PrimaryKey val id: Int,
    val firstName: String,
    val lastName: String
)DefiningDataSnippets.kt
注意：Room 需要能够访问属性，才能持久化它。应公开该属性，或提供 getter 和 setter 函数。

默认情况下，Room 用类名作为表名。若需要不同表名，设置 @Entity 标注的 tableName 属性。同样，默认用属性名作为列名；若需要不同列名，为属性添加 @ColumnInfo 并设置 name。下例自定义表名和列名：

@Entity(tableName = "users")
data class User(
    @PrimaryKey val id: Int,
    @ColumnInfo(name = "first_name") val firstName: String,
    @ColumnInfo(name = "last_name") val lastName: String
)DefiningDataSnippets.kt
注意：SQLite 的表名和列名不区分大小写。

定义主键

每个 Room 实体都必须定义主键，唯一标识相应表中的每一行。为某列添加 @PrimaryKey 即可：

@PrimaryKey val id: IntDefiningDataSnippets.kt
注意：若需要 Room 自动分配实体 ID，把 @PrimaryKey 的 autoGenerate 设为 true。

定义复合主键

若需要多个列的组合唯一标识实体实例，在 @Entity 的 primaryKeys 中列出这些列，定义复合主键：

@Entity(primaryKeys = ["firstName", "lastName"])
data class User(
    val firstName: String,
    val lastName: String
)DefiningDataSnippets.kt

忽略属性

默认情况下，Room 为实体的每个属性创建一列。若不希望持久化某属性，添加 @Ignore：

@Entity
data class User(
    @PrimaryKey val id: Int,
    val firstName: String,
    val lastName: String,
    @Ignore val picture: Bitmap? = null
)DefiningDataSnippets.kt
注意：若被忽略的属性声明在主构造器中，必须提供 null 等默认值，因为 Room 创建表时会忽略它，但从查询结果实例化类时，仍会调用主构造器。

如果实体从父实体继承属性，使用 @Entity 标注的 ignoredColumns：

open class User {
    var picture: Bitmap? = null
}

@Entity(ignoredColumns = ["picture"])
data class RemoteUser(
    @PrimaryKey val id: Int,
    val hasVpn: Boolean
) : User()DefiningDataSnippets.kt

提供表搜索能力

Room 支持多种标注，用于在数据库表中搜索信息。

支持全文搜索

若应用需要快速全文搜索（FTS），应让实体由虚拟表支持，使用 SQLite 的 FTS3 或 FTS4 扩展，或 FTS5 扩展。

为实体添加 @Fts3、@Fts4 或 @Fts5，即可使用这一能力。

// Use `@Fts3` only if your app has strict disk space requirements.
@Fts4
@Entity(tableName = "users")
data class User(
    // Specifying a primary key for an FTS-table-backed entity is optional,
    // but if you include one, it must an INTEGER type and column name "rowid".
    @PrimaryKey @ColumnInfo(name = "rowid") val id: Long,
    @ColumnInfo(name = "first_name") val firstName: String
)DefiningDataSnippets.kt
注意：启用 FTS 的表始终使用类型为 INTEGER、列名为 "rowid" 的主键。若 FTS 实体定义主键，必须采用这一类型和列名。

用 tokenizer 选项自定义 FTS 表的分词方式。Room 通过 FtsOptions 提供多种内置分词器，包括 TOKENIZER_SIMPLE、TOKENIZER_PORTER、TOKENIZER_UNICODE61：

@Fts4(tokenizer = FtsOptions.TOKENIZER_UNICODE61)
@Entity(tableName = "users")
data class User(
    @PrimaryKey @ColumnInfo(name = "rowid") val id: Long,
    @ColumnInfo(name = "first_name") val firstName: String
)DefiningDataSnippets.kt

Room 还提供结果排序、移除列索引、使用外部内容表等 FTS 实体选项。更多信息请参阅 FtsOptions。

为特定列建立索引

如果使用 AndroidSQLiteDriver，需要兼容不支持 FTS3、FTS4、FTS5 实体表的 SDK 版本，仍可对数据库特定列建立索引，加快查询。使用 BundledSQLiteDriver 时，Room 支持所有 FTS 版本，不受 Android SDK 版本影响。

在 @Entity 中加入 indices，为实体添加索引，并列出包含在索引或复合索引中的列名。示例如下：

@Entity(indices = [Index(value = ["last_name", "address"])])
data class User(
    @PrimaryKey val id: Int,
    @ColumnInfo(name = "first_name") val firstName: String,
    @ColumnInfo(name = "last_name") val lastName: String,
    val address: String?,
)DefiningDataSnippets.kt

数据库中的某些列或列组合可能需要唯一值。将 @Index 的 unique 设为 true 即可强制唯一性。下例展示这种做法：

@Entity(indices = [Index(value = ["first_name", "last_name"], unique = true)])
data class User(
    @PrimaryKey val id: Int,
    @ColumnInfo(name = "first_name") val firstName: String,
    @ColumnInfo(name = "last_name") val lastName: String,
)DefiningDataSnippets.kt
