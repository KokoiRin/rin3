如果这个操作只用一次，还需要给它取一个名字吗

上一篇用 n_times 把重复结构抽了出来。现在只想把 7 连续乘三四次，得到 567；为此在全局放一个 triple 有点分散。我们先把名字缩进需要它的地方，再进一步直接写出函数值。

fn y => 3 * y 的意思是“一个接收 y、返回 3*y 的函数”。这里的 y 是参数名，不是函数名；整个表达式求值得到函数值，交给 n_times，它并没有立即算出某个整数。这种没有单独取函数名的写法叫匿名函数。

fun 引入一个函数绑定，不能直接塞进本来要求一个表达式的位置。若一定要用 fun，可以写 let fun triple y = 3*y in triple end，整个 let 才是产生函数值的表达式。非递归的 fun f x = e 可以理解为 val f = fn x => e；需要以自己的新名字递归时，仍用 fun。val 右侧若碰到同名的旧绑定，引用的是旧名字，不会凭空变成自递归。

先看是不是已经有现成的函数值

匿名函数不是越多越好。下面两种尾部操作做的事情一样，但前者加了一层“接到输入，原样转交”的包装。

tl 本来就是所需函数，不需要再写 fn ys => tl ys。同理，fun rev xs = List.rev xs 若只是取一个别名，可以简化成 val rev = List.rev。后面会遇到值限制，使某些看似多余的包装承担类型泛化的作用；这里先识别最简单的原样转发。

因此类型是 ('a -> 'b) * 'a list -> 'b list，这里允许输入元素与输出元素不同。这个保证也有边界：map (hd, [[1],[]]) 会在第二个子列表处抛出 Empty，map 不会替传入的函数消除异常。

filter：保留哪些项，而不是把项变成什么

若目标变成“只保留偶数页数”，每次计算的是一个保留决定。返回布尔值的判断函数常叫 predicate，中文可称判断条件。

两个结果是 [4,8] 与 [("Tue",4),("Wed",8)]。第二个函数用模式 (_,v) 拆开每条记录，只检查第二项；第一项叫什么类型并不重要。filter 的类型是 ('a -> bool) * 'a list -> 'a list：它可以减少项数，却保留选中元素本身和相对顺序。

本篇自写 map、filter 接收一个二元组；标准库的 List.map、List.filter 则逐个接收参数。比如标准库写 List.map (fn x => x+1) [4,8]。两者思想相同，调用形式不能混用。
