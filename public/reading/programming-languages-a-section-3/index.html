Programming Languages, Part A · Section 3

函数带着环境走：从高阶操作到闭包与回调

从一个可配置的筛选器出发，追踪函数怎样被传递、怎样保存绑定，以及何时重新计算。熟悉的 Kotlin 用法简短对照，重点放在闭包、折叠、部分应用与共享状态的准确含义。

28 段视频 · 13 篇讲解7 组分步图解支持按问题选读

这一节要解决什么问题

把重复的控制流程和每次不同的操作拆开，读懂高阶函数的类型。

逐步追踪闭包所使用的定义处绑定，区分不可变值、计算时机和共享引用。

用同一组语义问题比较 ML、Java 与 C，理解方便写法背后的能力和限制。

想先看具体推演，可以从这里进入

  • 闭包在另一个位置调用时，究竟去哪里找变量？
  • 同一段计算放在闭包内外，为什么执行次数不同？
  • 两个名字或闭包共享同一个引用时，修改会影响谁？

图解可以前后切换、直接选择步骤，也可以展开全部状态；关闭脚本仍能阅读。来源与选学范围放在每篇开头的折叠说明中。

第 1 部分

让操作成为可以传递的值

先把流程里的变化提取成函数，再用匿名函数、映射与筛选复用已有控制流程。

01把变化的操作交给函数用 n_times 把重复的控制流程与每次执行的操作分开，再读懂高阶函数与多态类型的关系。对应 V01 / V02 / V0302临时操作、map 与 filter，怎样写得恰到好处把配置筛选写成小函数，辨别匿名表达式、无谓包装与真正返回函数的计算。对应 V04 / V05 / V06 / V07
第 2 部分

看清绑定、计算时机与累积顺序

函数离开定义位置后仍使用哪些值，哪些计算会重做，折叠和组合又怎样决定顺序。

03函数记住哪份配置：词法作用域与闭包分别追踪传入、返回的函数所使用的定义处绑定，避免把调用处的同名名字误当作捕获内容。对应 V08 / V09 / V1004闭包保存的是结果，还是以后要重复的计算移动一条绑定会怎样改变重算次数、执行时机与副作用，用短字符串筛选看清边界。对应 V1105fold 的每一步，到底先拿哪个值计算沿着累加器追踪左折叠，区分输入顺序、函数参数顺序、右折叠与短路谓词的实际行为。对应 V1206把转换、备用方案与管道接成一条过程比较函数组合的方向、流水线写法，以及返回 option 和抛异常时的两种备用策略。对应 V13
第 3 部分

把通用函数逐步变成专用函数

区分柯里化与元组输入，利用部分应用固定配置，再理解值限制为什么需要例外处理。

07一次交一项输入，为什么会得到另一个函数把柯里化还原成嵌套的一元函数，和元组参数区分，并看清箭头与应用的结合方向。对应 V1408先固定配置，再留下可复用的专用函数利用部分应用构造筛选器，并处理值限制、必要包装和元组式与柯里化接口的转换。对应 V15 / V16
第 4 部分

把环境带进共享状态、回调和其他语言

引入可变引用，观察闭包如何保存状态，并对照函数式封装与 Java、C 的表示办法。

09捕获不可变值，与共享一个可变位置追踪 ref、解引用与赋值，把同名遮蔽、别名和闭包共享状态分清楚。对应 V1710登记一个回调后，配置和状态会留在哪里从键盘事件注册看闭包捕获与回调顺序，再通过标准库文档核对类型、参数与边界。对应 V18 / V1911不用类，也能把数据和操作封在一起用原课整数集合的三个闭包理解抽象数据类型，区分不可变插入、新版本与共享私有表示。对应 V2012没有现成闭包时，环境要怎样一起传过去对照 Java 对象与 C 的函数指针加上下文，解释仅有代码地址缺少什么，以及对象与环境的生命周期。对应 V21 / V22 / V23
第 5 部分

从具体规则回到语言取舍

理解课程在学习路径中的位置，用明确问题比较语言，而不是只比语法熟悉度。

13学会这些概念以后，怎样判断语言的取舍把课程动机、语言定义、优秀语言的标准与取舍放在一起，形成可迁移的比较框架。对应 V24 / V25 / V26 / V27 / V28
