协程指南

Kotlin 标准库只提供最基本的底层 API，供其他库实现协程功能。与许多具有类似能力的语言不同，在 Kotlin 中，async 和 await 既不是关键字，也不属于标准库。此外，相比 future 和 promise，Kotlin 的挂起函数为异步操作提供了更安全、更不易出错的抽象方式。

kotlinx.coroutines 是 JetBrains 开发的协程库，功能丰富，提供了本指南介绍的多种高层协程原语，包括 launch 和 async。

本指南分主题介绍 kotlinx.coroutines 的核心功能，并配有一系列示例。

要使用协程并运行这些示例，需要按项目 README 的说明，添加 kotlinx-coroutines-core 模块依赖。
