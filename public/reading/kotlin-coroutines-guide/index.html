Kotlin 协程指南

Kotlin 标准库只提供实现协程所需的底层接口。你在示例里看到的 async 和 await 由库提供，在 Kotlin 里都不是关键字。处理异步操作时，Kotlin 还提供了挂起函数。相比通过 future 或 promise 交付结果，挂起函数能让这类代码更安全，减少出错的机会。

本指南使用 JetBrains 开发的 kotlinx.coroutines 库。它在底层接口之上提供了可以直接使用的协程工具，例如用 launch 启动任务，用 async 启动将来需要取回结果的任务。

编者注

示例里出现的 suspend 属于 Kotlin 语言。launch、async 和 delay 则来自协程库，所以跟着输入代码之前，要先把下文提到的依赖加进项目。

下面的章节分主题介绍 kotlinx.coroutines 的核心功能，每个主题都配有代码示例。

如果想跟着运行示例，请先按项目 README 的说明，在自己的项目里添加 kotlinx-coroutines-core 依赖。
