BEGINNER

初学者

先建立语法骨架：值、类型、集合、分支、函数、对象与空值。

01 Hello world 与变量从程序入口、val 与 var 开始，学会把值放进变量，再用字符串模板把结果表达出来。 02 基本类型理解类型推断、显式类型声明，以及整数、浮点数、布尔值、字符和字符串。 03 集合用 List、Set 与 Map 组织一组值，并分清只读视图与可变集合。 04 控制流通过 if、when、区间和循环，让程序根据条件选择路线并重复执行。 05 函数学习参数、返回值、默认参数、命名参数，以及把行为当作值传递的 lambda。 06 类用类把数据与行为放在一起，并通过 data class 获得常用的数据对象能力。 07 空安全把“可能没有值”写进类型，并用空值检查、安全调用和 Elvis 运算符处理它。
INTERMEDIATE

中级

再理解 Kotlin 怎样组织上下文、扩展行为、抽象类型并控制不确定性。

01 扩展函数在不修改原类的前提下，为类型补充可以像成员函数一样调用的新能力。 02 作用域函数分清 let、apply、run、also 与 with 如何引用上下文对象、返回什么结果。 03 带接收者的 lambda让 lambda 在某个对象的上下文中执行，为构建器和领域专用语言打下基础。 04 类与接口理解继承、抽象类、接口实现与类委托，建立可替换的行为边界。 05 对象使用对象声明、数据对象与伴生对象表达单例和与类型相关的共享能力。 06 开放类与特殊类通过 open、sealed、enum 与 value class 控制继承范围并表达有限状态和值语义。 07 属性理解幕后字段、扩展属性与委托属性，控制值如何计算、保存和观察。 08 进阶空安全结合智能转换、安全类型转换、集合处理与提前返回，缩短可空值的影响范围。 09 库与 API认识标准库、第三方库、API 稳定性与 opt-in，学会先查找再自己实现。
