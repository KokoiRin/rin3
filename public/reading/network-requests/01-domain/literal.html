域名与 DNS

输入一个域名之后，客户端怎样找到服务器？

先区分域名和 IP 地址：前者便于人使用，后者用于网络寻址。本篇后半段介绍 DNS 查询；域名购买部分可以先略读，原文仍完整保留。

阅读前的版本与适用范围校注（2 条）

原文把 DNS 描述为信息刷新到每台服务器，是教学上的简化。实际是分布式、分层的系统：权威服务器保存所负责区域的数据，递归解析器按需查询并缓存，缓存按 TTL 过期；并不是向全球所有 DNS 服务器推送完整数据库。根、顶级域和具体区域的权威服务也不应混为一谈。参见 RFC 1034，第 4～5 节。

原文使用公共 IP 的简化模型，不代表每台联网设备都能从公网直接访问。下面 whois 输出、域名可注册状态和政策例子都是原文示例，不是今天的实时查询结果；正文按原样保留。

概述

域名是互联网基础设施的重要组成部分。它们为互联网上可访问的任何 Web 服务器提供人类可读的地址。

任何接入互联网的计算机，都可以通过公共 IP 地址访问；这个地址可以是 IPv4 地址（例如 192.0.2.172），也可以是 IPv6 地址（例如 2001:db8:8b73:0000:0000:8a2e:0370:1337）。

计算机很容易处理这些地址，但人们很难据此判断谁在运行服务器，或者网站提供什么服务。IP 地址难以记忆，而且可能随时间变化。

为了解决这些问题，我们使用人类可读的地址，称为域名。

深入了解

域名的结构

域名的结构很简单，由若干部分组成（可能只有一部分，也可能有两部分、三部分……），各部分用点分隔，并且从右向左阅读：

每一部分都提供关于整个域名的特定信息。

TLD（顶级域）。

TLD 告诉用户域名背后服务的一般用途。最通用的 TLD（.com、.org、.net）不要求 Web 服务满足特定标准，但有些 TLD 执行更严格的政策，使其用途更加明确。例如：

  • .us、.fr 或 .se 这样的地区 TLD，可能要求服务使用特定语言，或者托管在特定国家；它们本来就是用来指示特定语言或国家的资源的。
  • 包含 .gov 的 TLD 只允许政府部门使用。
  • .edu TLD 仅供教育和学术机构使用。

TLD 除了拉丁字符，也可以包含特殊字符。TLD 最长为 63 个字符，不过大多数长度在 2～3 个字符左右。

完整的 TLD 列表由 ICANN 维护。

标签（或组成部分）

标签是接在 TLD 后面的部分。标签是一个不区分大小写的字符序列，长度为 1～63 个字符，只能包含字母 A 到 Z、数字 0 到 9，以及“-”字符（不能位于标签的开头或结尾）。a、97 和 hello-strange-person-16-how-are-you 都是有效标签的例子。

紧挨着 TLD、位于其前面的标签，也称为二级域（SLD）。

一个域名可以有许多标签（或组成部分）。组成域名并不强制要求、也不必一定使用 3 个标签。例如，informatics.ed.ac.uk 就是有效域名。对于你控制的任何域名（例如 mozilla.org），你都可以创建“子域名”，让每个子域名提供不同的内容，例如 developer.mozilla.org、support.mozilla.org 或 bugzilla.mozilla.org。

购买域名

谁拥有域名？

你不能“买下一个域名”。这样做是为了让不再使用的域名最终能重新供其他人使用。如果每个域名都被买断，网络很快就会充斥着被锁定、无人使用、其他人也无法使用的域名。

实际上，你付费购买的是一年或多年的域名使用权。你可以续期，而且你的续期优先于其他人的申请。但你永远不会拥有这个域名。

被称为注册商的公司，通过域名注册数据库记录将你与域名关联起来的技术信息和管理信息。

备注：对于某些域名，负责记录信息的可能不是注册商。例如，.fire 下的所有域名都由 Amazon 管理。

寻找可用的域名

要确定某个域名是否可用：

  • 访问域名注册商的网站。大多数注册商提供“whois”服务，用来告诉你某个域名是否可用。

  • 或者，如果你使用的系统内置了 shell，可以在其中输入 whois 命令，下面以 mozilla.org 为例：

    bash
    whois mozilla.org

获取域名

过程相当直接：

  1. 访问注册商的网站。
  2. 通常会有一个醒目的“获取域名”操作入口。点击它。
  3. 填写表单中所有必需的信息。尤其要确保你想要的域名没有拼写错误。一旦付款，就来不及了！
  4. 注册商会在域名注册成功时通知你。几个小时内，所有 DNS 服务器都会收到你的 DNS 信息。

备注：在这个过程中，注册商会要求你提供现实中的地址。请务必准确填写，因为在某些国家，如果注册商无法提供有效地址，可能会被要求关闭该域名。

DNS 刷新

DNS 数据库存储在世界各地的每台 DNS 服务器上，这些服务器都会引用少数被称为“权威域名服务器”或“顶级 DNS 服务器”的特殊服务器；它们就像管理整个系统的主管服务器。

每当注册商为某个域名创建或更新信息时，每个 DNS 数据库中的信息都必须刷新。每台知道这个域名的 DNS 服务器，都会先将信息存储一段时间，然后让它自动失效并刷新（DNS 服务器查询权威服务器，从那里获取更新的信息）。因此，知道这个域名的 DNS 服务器需要一些时间，才能获得最新信息。

DNS 请求如何工作？

正如前面所见，当你想在浏览器中显示网页时，输入域名比输入 IP 地址更容易。我们来看看这个过程：

  1. 在浏览器地址栏中输入 mozilla.org。
  2. 浏览器询问你的计算机，是否已经知道这个域名对应的 IP 地址（使用本地 DNS 缓存）。如果知道，就把域名转换成 IP 地址，浏览器随后与 Web 服务器协商获取内容。过程到此结束。
  3. 如果计算机不知道 mozilla.org 这个名称背后的 IP，就会继续询问 DNS 服务器；DNS 服务器的工作恰好就是告诉计算机，每个已注册的域名对应哪个 IP 地址。
  4. 现在计算机知道了请求所需的 IP 地址，浏览器就可以与 Web 服务器协商获取内容。
