Monad 的代数

Bartosz Milewski

把代数与 Monad 放在一起，我们会得到 Eilenberg–Moore 范畴与 Kleisli 范畴，也会看见行为良好的 Lens 正是 Store Comonad 的余代数。

译文范围

完整翻译正文，保留全部原文代码、图片、公式及 3 道习题；关键术语附英文原文，习题附可展开答案。

如果把自函子解释为定义表达式的方式，那么代数让我们能够求值这些表达式，而 Monad 让我们能够形成并操纵它们。把代数与 Monad 结合起来，不仅会获得大量功能，还能回答一些有趣的问题。

其中一个问题涉及 Monad 与伴随（adjunction）之间的关系。正如我们所见，每个伴随都会定义一个 Monad（以及一个 Comonad）。问题是：每个 Monad（Comonad）都能从某个伴随导出吗？答案是肯定的。能够生成给定 Monad 的伴随有整整一族。这里会展示其中两个。

先复习定义。Monad 是一个自函子 m，配备两个满足若干相容条件的自然变换。它们在 a 处的分量是：

ηa: a → m a
μa: m (m a) → m a

同一个自函子上的代数，是选出一个特定对象——载体（carrier）a——以及一个态射：

alg: m a → a

首先要注意，代数的方向与 ηa 相反。直觉上，ηa 从一个 a 类型的值创建平凡表达式。使代数与 Monad 兼容的第一条相容条件保证：用载体为 a 的代数求值这个表达式，会拿回原来的值：

alg ∘ ηa = ida

第二条条件来自这样一个事实：对双重嵌套的表达式 m (m a) 有两种求值方式。可以先应用 μa 把表达式压平，再用代数的求值器；也可以先应用提升后的求值器来求值内部表达式，再对结果应用求值器。我们希望两种策略等价：

alg ∘ μa = alg ∘ m alg

这里的 m alg 是用函子 m 提升 alg 得到的态射。下面两个交换图描述了这两条条件（为后文铺垫，我把 m 换成了 T）：

a ─ηa→ Ta ─alg→ a = a

T(Ta) ─T alg→ Ta ─alg→ a
　│ μa　　　　　↑
　└────────→ Ta ─alg→ a

也可以用 Haskell 表达这些条件：

alg . return = id
alg . join = alg . fmap alg

来看一个小例子。列表自函子上的代数由某个类型 a，以及一个从 a 的列表产生 a 的函数组成。假设通过选择相同的元素类型与累加器类型 a，用 foldr 表达这个函数：

foldr :: (a -> a -> a) -> a -> [a] -> a

这个特定代数由一个双参数函数——称为 f——和一个值 z 指定。列表函子碰巧也是 Monad，其中 return 把一个值变成单元素列表。代数（这里是 foldr f z）与 return 复合后，把 x 映射为：

foldr f z [x] = x `f` z

这里用中缀记法书写 f 的作用。如果下面的相容条件对每个 x 都成立，这个代数便与 Monad 兼容：

x `f` z = x

把 f 看成二元运算符，这条条件告诉我们 z 是右单位元。

第二条相容条件作用于列表的列表。join 的作用是拼接各个列表，之后可以折叠所得列表。另一方面，也可以先分别折叠各个列表，再折叠所得列表。再次把 f 解释为二元运算符，这条条件告诉我们该二元运算满足结合律。当 (a, f, z) 是幺半群（monoid）时，这些条件当然成立。

T-代数

数学家喜欢把 Monad 称为 T，所以把与它兼容的代数称为 T-代数（T-algebra）。范畴 C 中给定 Monad T 的 T-代数构成一个范畴，叫作 Eilenberg–Moore 范畴（Eilenberg–Moore category），常记为 CT。这个范畴中的态射是代数同态，也就是我们为 F-代数定义过的那种同态。

T-代数是由载体对象与求值器组成的二元组 (a,f)。有一个显然的遗忘函子（forgetful functor）UT:CT→C，把 (a,f) 映射为 a；它也把 T-代数同态映射为 C 中载体对象之间对应的态射。你也许还记得，遗忘函子的左伴随称为自由函子（free functor）。

UT 的左伴随称为 FT。它把 C 中对象 a 映射为 CT 中的自由代数（free algebra）。这个自由代数的载体是 Ta，求值器是从 T(Ta) 回到 Ta 的态射。因为 T 是 Monad，可以用 Monad 的 μa（Haskell 中的 join）作为求值器。

仍需证明它确实是 T-代数。为此必须满足两条相容条件：

alg ∘ ηTa = idTa
alg ∘ μa = alg ∘ T alg

但只要把 μ 代入代数，这两条恰好就是 Monad 定律。

你也许还记得，每个伴随都会定义一个 Monad。事实证明，FT 与 UT 之间的伴随所定义的，正是构造 Eilenberg–Moore 范畴时使用的 Monad T。因为每个 Monad 都能进行这种构造，所以可以得出：每个 Monad 都能由一个伴随生成。稍后还会看到另一个生成同一 Monad 的伴随。

计划如下：先通过定义伴随的单位与余单位，并证明相应的三角恒等式成立，说明 FT 确实是 UT 的左伴随；然后说明这个伴随生成的 Monad 确实是原来的 Monad。

伴随的单位是自然变换：

η:I → UT∘FT

计算这个变换在 a 处的分量。恒等函子给出 a；自由函子产生自由代数 (Ta,μa)；遗忘函子把它缩减为 Ta。合起来得到从 a 到 Ta 的映射。我们直接用 Monad T 的单位作为这个伴随的单位。

再看余单位：

ε:FT∘UT → I

计算它在某个 T-代数 (a,f) 处的分量。遗忘函子忘掉 f，自由函子产生二元组 (Ta,μa)。所以，要定义余单位 ε 在 (a,f) 处的分量，需要 Eilenberg–Moore 范畴中合适的态射，也就是 T-代数同态：

(Ta,μa) → (a,f)

这样的同态应该把载体 Ta 映射到 a。那就让被遗忘的求值器 f 复活。这一次把它用作 T-代数同态。确实，使 f 成为 T-代数的同一个交换图，也可重新解释为证明它是 T-代数同态：

T(Ta) ─Tf→ Ta
　│ μa　　　│ f
　↓　　　　　↓
Ta ───f──→ a

由此，我们把余单位自然变换 ε 在 (a,f)（T-代数范畴中的对象）处的分量定义为 f。

要完成伴随，还需证明单位与余单位满足三角恒等式：

Ta ─Tηa→ T(Ta) ─μa→ Ta = Ta

a ─ηa→ Ta ─f→ a = a

第一条由 Monad T 的单位律成立；第二条正是 T-代数 (a,f) 的定律。

至此已经确定两个函子形成伴随：

FT ⊣ UT

每个伴随都产生一个 Monad。往返复合：

UT∘FT

是 C 中产生相应 Monad 的自函子。看看它对对象 a 的作用：FT 创建的自由代数是 (Ta,μa)，UT 丢掉求值器。因此确实有：

UT∘FT = T

正如预期，伴随的单位就是 Monad T 的单位。

你也许还记得，伴随的余单位通过下面的公式产生 Monad 乘法：

μ = R∘ε∘L

这是三个自然变换的水平复合，其中两个是恒等自然变换，分别把 L 映射到 L、把 R 映射到 R；中间的余单位，是一个在代数 (a,f) 处以 f 为分量的自然变换。

计算分量 μa。先把 ε 水平复合在 FT 之后，结果是 ε 在 FTa 处的分量。因为 FT 把 a 变成代数 (Ta,μa)，而 ε 选出求值器，所以最终得到 μa。左侧与 UT 的水平复合不会改变任何东西，因为 UT 对态射的作用是平凡的。因此，从伴随得到的 μ 确实就是原 Monad T 的 μ。

Kleisli 范畴

我们以前见过 Kleisli 范畴（Kleisli category）。它由另一个范畴 C 与一个 Monad T 构造而来，记作 CT。Kleisli 范畴 CT 的对象与 C 的对象相同，但态射不同。Kleisli 范畴中从 a 到 b 的态射 fK，对应原范畴中从 a 到 Tb 的态射 f。我们把这个态射称为从 a 到 b 的 Kleisli 箭头（Kleisli arrow）。

Kleisli 范畴中的态射复合，用 Kleisli 箭头的 Monad 复合定义。例如，把 gK 复合在 fK 之后。在 Kleisli 范畴中有：

fK:a→b
gK:b→c

它们在范畴 C 中对应：

f:a→Tb
g:b→Tc

把复合 hK=gK∘fK 定义成 C 中的 Kleisli 箭头：

h:a→Tc
h=μ∘(Tg)∘f

在 Haskell 中写作：

h = join . fmap g . f

有一个从 C 到 CT 的函子 F，它对对象的作用是平凡的；对态射，它把 C 中的 f 映射为 CT 中的态射，方法是创建一个为 f 的返回值加上修饰的 Kleisli 箭头。给定态射 f:a→b，它在 CT 中创建的态射所对应的 Kleisli 箭头是 η∘f。Haskell 中写作：

return . f

还可以定义一个从 CT 回到 C 的函子 G。它把 Kleisli 范畴中的对象 a 映射为 C 中的对象 Ta。对于对应 Kleisli 箭头 f:a→Tb 的态射 fK，它映射到 C 中从 Ta 到 Tb 的态射：先提升 f，再应用 μ，即 μb∘Tf。用 Haskell 记法：

G fT = join . fmap f

你也许认得，这是用 join 定义 Monad bind。

很容易看出这两个函子形成伴随：

F ⊣ G

而它们的复合 G∘F 再现原来的 Monad T。

这就是产生同一 Monad 的第二个伴随。事实上，存在一个伴随的范畴 Adj(C,T)，其中每个伴随都会在 C 上产生相同的 Monad T。刚看到的 Kleisli 伴随是这个范畴的始对象，Eilenberg–Moore 伴随则是终对象。

Comonad 的余代数

对任何 Comonad W 都能进行类似构造。可以定义一个与 Comonad 兼容的余代数范畴。它们使下面的图交换：

a ─coa→ Wa ─εa→ a = a

a ─coa→ Wa ─W coa→ W(Wa)
│　　　　　↑
└─coa→ Wa ─δa→ W(Wa)

其中 coa 是载体为 a 的余代数的余求值态射（coevaluation morphism）：

coa:a→Wa

而 ε 与 δ 是定义 Comonad 的两个自然变换（在 Haskell 中，它们的分量分别叫作 extract 与 duplicate）。

从这些余代数所成的范畴到 C，有一个显然的遗忘函子 UW，它只会忘掉余求值器。我们考虑它的右伴随 FW：

UW ⊣ FW

遗忘函子的右伴随称为余自由函子（cofree functor）。FW 生成余自由余代数：它把 C 中对象 a 指派为余代数 (Wa,δa)。这个伴随通过相应的复合再现原来的 Comonad。

译注：原文此处把复合写成 FW∘UW。按函子的定义域和值域，C 上生成原 Comonad W 的复合应为 UW∘FW；原文顺序会得到余代数范畴上的 Monad。

类似地，可以构造带有 co-Kleisli 箭头的 co-Kleisli 范畴（co-Kleisli category），并从相应伴随重新生成这个 Comonad。

Lens

回到 Lens。对于函子 Store s，Lens 可以写成余代数：

coalgs:a→Store s a
data Store s a = Store (s -> a) s

这个余代数也可表达为一对函数：

set:a→s→a
get:a→s

（可以把 a 想成“全部”（all），把 s 想成它的一个“小”（small）部分。）用这对函数，有：

coalgs a = Store (set a) (get a)

这里的 a 是一个 a 类型的值。注意，部分应用的 set 是一个 s→a 的函数。

我们还知道 Store s 是 Comonad：

instance Comonad (Store s) where
  extract (Store f s) = f s
  duplicate (Store f s) = Store (Store f) s

问题是：在什么条件下，Lens 是这个 Comonad 的余代数？第一条相容条件：

εa∘coalg=ida

翻译为：

set a (get a) = a

这条 Lens 定律表达的是：如果把结构 a 的某个字段设为它原来的值，结构不会改变。这条定律也称为 GETPUT。

第二条条件：

fmap coalg∘coalg=δa∘coalg

需要多做一点工作。先回忆 Store 函子的 fmap 定义：

fmap g (Store f s) = Store (g . f) s

把 fmap coalg 应用于 coalg 的结果，得到：

Store (coalg . set a) (get a)

另一方面，对 coalg 的结果应用 duplicate，得到：

Store (Store (set a)) (get a)

要使这两个表达式相等，Store 内的两个函数作用于任意 s 时必须相等：

coalg (set a s) = Store (set a) s

展开 coalg，得到：

Store (set (set a s)) (get (set a s)) = Store (set a) s

这等价于余下两条 Lens 定律。第一条：

set (set a s) = set a

告诉我们，把一个字段的值设置两次与设置一次相同。这条定律也称为 PUTPUT。第二条：

get (set a s) = s

告诉我们，把字段设为 s 后再读取它，会得到 s。这条定律也称为 PUTGET。

满足 GETPUT 与 PUTGET 的 Lens 称为行为良好的 Lens（well-behaved lens）。若还满足 PUTPUT，则称为行为非常良好的 Lens（very well behaved lens）。换句话说，行为非常良好的 Lens 确实就是 Store 函子的 Comonad 余代数。

习题

  1. 自由函子 FT:C→CT 对态射如何作用？提示：使用 Monad 乘法 μ 的自然性条件。
    点击展开参考答案

    给定 C 中态射 h:a→b，定义 FTh=T h。它必须成为从自由代数 (Ta,μa) 到 (Tb,μb) 的代数同态，即：

    μb∘T(T h)=(T h)∘μa

    这恰好是自然变换 μ:T²→T 对态射 h 的自然性方块。因此 FT 对态射的作用就是用 T 提升它。

  2. 定义伴随 UW⊣FW。
    点击展开参考答案

    令 CoalgW 为与 W 兼容的余代数范畴。UW:CoalgW→C 忘掉余代数结构；FW:C→CoalgW 把 b 送到余自由余代数 (Wb,δb)，把 g:b→c 送到 Wg。

    自然同构为：

    CoalgW((a,coa),FWb) ≅ C(a,b)

    从左向右把余代数同态 h:a→Wb 映为 εb∘h；从右向左把 f:a→b 映为 Wf∘coa。Comonad 定律、自然性和余代数定律说明两种构造互逆。

  3. 证明上述伴随再现原来的 Comonad。
    点击展开参考答案

    C 上由 UW⊣FW 产生的 Comonad，其底层自函子是：

    UW∘FW

    对对象 a，FW 先产生 (Wa,δa)，UW 再忘掉结构，因此得到 Wa；对态射 f 得到 Wf。所以底层函子就是 W。伴随的余单位在 a 处是 εa；由伴随单位生成的 comultiplication 在 a 处是 δa。因此所得 Comonad 的三个组成部分恰为原来的 (W,ε,δ)。
