布局决定了应用界面的结构，比如 Activity 中的界面。布局里的所有元素，都是由 View 和 ViewGroup 对象一层层组织起来的。View 通常负责画出用户看得到、也能操作的内容。ViewGroup 则是一个看不见的容器，用来安排 View 和其他 ViewGroup 对象的布局结构，如图 1 所示。

View 对象通常叫作控件，具体可以是它的各种子类，比如 Button 或 TextView。ViewGroup 对象通常叫作布局，不同类型提供不同的布局结构，比如 LinearLayout 和 ConstraintLayout。

可以通过两种方式声明布局：

  • 在 XML 中声明界面元素。Android 提供的 XML 写法很直观，对应着控件、布局等 View 类及其子类。你也可以打开 Android Studio 的布局编辑器，通过拖放来搭建 XML 布局。
  • 在运行时创建布局元素。应用可以创建 View 和 ViewGroup 对象，再用代码修改它们的属性。

把界面写在 XML 中，就能将“界面长什么样”和“控制界面行为的代码”分开。使用 XML 文件，也更容易为不同屏幕尺寸和方向提供不同布局。具体可以看支持不同屏幕尺寸。

Android 允许你任选一种方式，也允许两种一起用。比如，先在 XML 中声明默认布局，再在应用运行时修改它。

提示：想在应用运行时调试布局，可以使用布局检查器工具。

编写 XML

用 Android 的 XML 写法，可以快速设计界面布局和其中的屏幕元素。这和写 HTML 网页类似：把一组元素层层嵌套起来，组成页面。

每个布局文件必须有且只有一个根元素，它必须是 View 或 ViewGroup 对象。确定根元素后，就可以往里面添加布局对象或控件作为子元素，逐步组成描述布局的 View 层次结构。比如，下面的 XML 用一个垂直排列的 LinearLayout，放入一个 TextView 和一个 Button：

<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
              android:layout_width="match_parent"
              android:layout_height="match_parent"
              android:orientation="vertical" >
    <TextView android:id="@+id/text"
              android:layout_width="wrap_content"
              android:layout_height="wrap_content"
              android:text="Hello, I am a TextView" />
    <Button android:id="@+id/button"
            android:layout_width="wrap_content"
            android:layout_height="wrap_content"
            android:text="Hello, I am a Button" />
</LinearLayout>

写好 XML 布局后，把文件扩展名设为 .xml，保存在 Android 项目的 res/layout/ 目录下，这样才能正确编译。

布局 XML 还支持哪些语法，可以看布局资源。

加载 XML 资源

编译应用时，每个 XML 布局文件都会被编译成一个 View 资源。你需要在应用的 Activity.onCreate() 回调中加载它：调用 setContentView()，按 R.layout.layout_file_name 的形式传入布局资源引用。比如，XML 文件名是 main_layout.xml，就可以这样为 Activity 加载布局：

Kotlin

fun onCreate(savedInstanceState: Bundle) {
    super.onCreate(savedInstanceState)
    setContentView(R.layout.main_layout)
}

Java

public void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    setContentView(R.layout.main_layout);
}

Activity 启动时，Android 会调用它的 onCreate() 回调。关于 Activity 生命周期的更多说明，可以看 Activity 简介。

属性

每个 View 和 ViewGroup 对象都有自己支持的 XML 属性。有些属性是特定 View 对象才有的，比如 TextView 支持 textSize；继承这个类的 View 对象，也会继承这些属性。有些则是所有 View 对象都有的，比如 id，因为它们都继承自根 View 类。还有一类叫布局参数：它们由父 ViewGroup 定义，用来描述这个 View 在布局中该怎样安排。

ID

你可以给任意 View 对象关联一个整数 ID，用它在树中唯一标识这个 View。应用编译后，通过整数引用这个 ID；但在编写布局 XML 时，通常会把它写成字符串，赋给 id 属性。这个属性由 View 类定义，是所有 View 对象共有的 XML 属性，也会经常用到。在 XML 标签中，ID 的写法如下：

android:id="@+id/my_button"

字符串开头的 @ 符号告诉 XML 解析器：解析并展开后面的 ID 字符串，把它识别为 ID 资源。加号（+）则表示这是一个新的资源名称，需要创建它，并添加到 R.java 文件的资源中。

Android 框架本身也提供了许多 ID 资源。引用这些 ID 时，不用写加号，但要加上 android 包命名空间，写法如下：

android:id="@android:id/empty"

加上 android 包命名空间，就表示这个 ID 来自 android.R 资源类，而不是应用本地的资源类。

创建 View，并在应用中引用它，通常可以这样做：

  1. 先在布局文件中定义 View，给它一个唯一 ID，如下所示：
    <Button android:id="@+id/my_button"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="@string/my_button_text"/>
  2. 再创建 View 对象的实例，并从布局中取得它。这一步通常放在 onCreate() 方法里，如下所示：

    Kotlin

    val myButton: Button = findViewById(R.id.my_button)

    Java

    Button myButton = (Button) findViewById(R.id.my_button);

使用 RelativeLayout 时，给 View 设置 ID 很重要。因为在相对布局中，一个 View 可以根据另一个同级 View 来确定自己的布局，而要找到那个 View，就需要它的唯一 ID。

ID 不一定要在整棵树中唯一，但必须在你搜索的那部分树中唯一。由于搜索范围经常就是整棵树，所以最好尽量让 ID 不重复。

布局参数

名字形如 layout_something 的 XML 属性，是给 View 设置布局参数的。这些参数要符合它所在的 ViewGroup 的要求。

每个 ViewGroup 类都有一个继承 ViewGroup.LayoutParams 的嵌套类。这个子类里的属性，会按照对应 ViewGroup 的规则，定义各个子 View 的大小和位置。如图 2 所示，每个子 View 的布局参数都由父 ViewGroup 定义，子 ViewGroup 也不例外。

每种 LayoutParams 子类都有自己的赋值方式。每个子元素都必须使用适合父元素的 LayoutParams；如果它自己还有子元素，也可以为这些子元素定义另一种 LayoutParams。

所有 ViewGroup 都通过 layout_width 和 layout_height 表示宽度和高度，每个 View 都必须定义这两项。许多 LayoutParams 还允许设置外边距和边框，这些是可选的。

你可以把宽度和高度设为精确的数值，但通常不必总是这样做。更常见的方式，是使用下面的常量之一：

  • wrap_content：让 View 按内容需要的大小来确定自己的尺寸。
  • match_parent：让 View 尽可能占满父 ViewGroup 允许的空间。

通常不建议用像素这样的绝对单位设置布局宽高。更合适的是密度无关像素（dp）、wrap_content 或 match_parent 等相对度量方式，这样应用更容易在不同尺寸的设备屏幕上正常显示。可以使用哪些度量类型，见布局资源。

布局位置

View 的形状是一个矩形。用左侧和顶部两个坐标表示位置，用宽度和高度表示尺寸。这些值的单位都是像素。

调用 getLeft() 和 getTop()，就能取得 View 的位置。前者返回矩形左侧的 x 坐标，后者返回顶部的 y 坐标。注意，这些位置是相对于父级的。比如，getLeft() 返回 20，就表示这个 View 的左边缘，在直接父级的左边缘向右 20 像素的位置。

想知道右边缘和底边缘的位置，也不用自己算，可以直接调用 getRight() 和 getBottom()。它们返回的就是 View 矩形右边缘、底边缘的坐标。比如，调用 getRight()，就相当于计算 getLeft() + getWidth()。

尺寸、内边距和外边距

View 的大小由宽度和高度表示，但每个 View 实际上有两组宽高值。

第一组是测量宽度和测量高度，表示 View 希望在父级中占多大空间。调用 getMeasuredWidth() 和 getMeasuredHeight()，就能取得这组测量值。

第二组是宽度和高度，有时也叫绘制宽度和绘制高度。它们表示布局完成后，绘制时 View 在屏幕上实际有多大。这组值可能和测量宽高相同，也可能不同。调用 getWidth() 和 getHeight()，就能取得它们。

测量大小时，View 还会把内边距算进去。内边距就是 View 内部左、上、右、下各侧的留白，单位是像素。你可以用它把内容向内移动一定距离。比如，左内边距设为 2，内容就会从左边缘向右移 2 像素。用 setPadding(int, int, int, int) 设置内边距，再用 getPaddingLeft()、getPaddingTop()、getPaddingRight() 和 getPaddingBottom() 查询各侧的值。

View 自己可以定义内边距，但不支持外边距。外边距由 ViewGroup 支持，具体可以看 ViewGroup 和 ViewGroup.MarginLayoutParams。

关于尺寸的更多说明，可以看尺寸。

除了用代码设置外边距和内边距，你也可以直接写在 XML 布局中：

  <?xml version="1.0" encoding="utf-8"?>
  <LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
                android:layout_width="match_parent"
                android:layout_height="match_parent"
                android:orientation="vertical" >
      <TextView android:id="@+id/text"
                android:layout_width="wrap_content"
                android:layout_height="wrap_content"
                android:layout_margin="16dp"
                android:padding="8dp"
                android:text="Hello, I am a TextView" />
      <Button android:id="@+id/button"
              android:layout_width="wrap_content"
              android:layout_height="wrap_content"
              android:layout_marginTop="16dp"
              android:paddingBottom="4dp"
              android:paddingEnd="8dp"
              android:paddingStart="8dp"
              android:paddingTop="4dp"
              android:text="Hello, I am a Button" />
  </LinearLayout>

上面的例子同时设置了外边距和内边距。TextView 四周使用相同的值；Button 则展示了怎样给不同边缘分别设置。

注意：建议用 paddingStart、paddingEnd、layout_marginStart 和 layout_marginEnd，替代 paddingLeft、paddingRight、layout_marginLeft 和 layout_marginRight。这样无论语言是从左向右书写，还是从右向左书写，布局都能更好地适配。

为适配器视图填充数据

要给 AdapterView 填充内容，比如 ListView 或 GridView，可以把它绑定到一个 Adapter。Adapter 会从外部数据源取出数据，再为每条数据创建对应的 View。

Android 提供了多种 Adapter 子类，用来读取不同类型的数据，并为 AdapterView 创建 View。最常用的是下面两种：

ArrayAdapter
如果数据源是数组，可以用这个 Adapter。默认情况下，ArrayAdapter 会逐项调用 toString()，把结果放进 TextView，这样就为数组里的每一项创建了 View。

比如，你有一个字符串数组，要把它显示在 ListView 中。可以新建一个 ArrayAdapter，在构造器中传入每个字符串使用的布局，以及这个字符串数组：

Kotlin

    val adapter = ArrayAdapter<String>(this, android.R.layout.simple_list_item_1, myStringArray)

Java

    ArrayAdapter<String> adapter = new ArrayAdapter<String>(this,
            android.R.layout.simple_list_item_1, myStringArray);

这个构造器接收以下参数：

  • 应用的 Context
  • 一个包含 TextView 的布局，用来显示数组中的每个字符串
  • 字符串数组

然后，对 ListView 调用 setAdapter()：

Kotlin

    val listView: ListView = findViewById(R.id.listview)
    listView.adapter = adapter

Java

    ListView listView = (ListView) findViewById(R.id.listview);
    listView.setAdapter(adapter);

如果想自定义每一项的外观，可以重写数组中对象的 toString() 方法。如果每项需要的 View 不是 TextView，比如希望每个数组项显示成 ImageView，就继承 ArrayAdapter 并重写 getView()，为每项返回需要的 View 类型。

SimpleCursorAdapter
如果数据来自 Cursor，可以用这个 Adapter。使用 SimpleCursorAdapter 时，需要说明两件事：Cursor 的每一行用什么布局，以及把 Cursor 的哪些列放进布局里的哪些 View。比如，要显示一个姓名和电话号码列表，可以先查询数据，得到一个 Cursor：每个人占一行，姓名和号码分别占一列。接着准备两个数组：字符串数组指定每条结果要使用 Cursor 中的哪些列，整数数组指定这些列分别放进哪个 View：

Kotlin

    val fromColumns = arrayOf(ContactsContract.Data.DISPLAY_NAME,
                              ContactsContract.CommonDataKinds.Phone.NUMBER)
    val toViews = intArrayOf(R.id.display_name, R.id.phone_number)

Java

    String[] fromColumns = {ContactsContract.Data.DISPLAY_NAME,
                            ContactsContract.CommonDataKinds.Phone.NUMBER};
    int[] toViews = {R.id.display_name, R.id.phone_number};

创建 SimpleCursorAdapter 时，传入每条结果使用的布局、保存查询结果的 Cursor，以及刚才准备的两个数组：

Kotlin

    val adapter = SimpleCursorAdapter(this,
            R.layout.person_name_and_number, cursor, fromColumns, toViews, 0)
    val listView = getListView()
    listView.adapter = adapter

Java

    SimpleCursorAdapter adapter = new SimpleCursorAdapter(this,
            R.layout.person_name_and_number, cursor, fromColumns, toViews, 0);
    ListView listView = getListView();
    listView.setAdapter(adapter);

之后，SimpleCursorAdapter 就会按你提供的布局，为 Cursor 的每一行创建 View，并把每个 fromColumns 项放入对应的 toViews View。

如果应用运行期间，你修改了 Adapter 读取的底层数据，就调用 notifyDataSetChanged()。它会告诉关联的 View“数据变了”，View 随后会刷新自己。

处理点击事件

想响应 AdapterView 中每一项的点击，可以实现 AdapterView.OnItemClickListener 接口。例如：

Kotlin

listView.onItemClickListener = AdapterView.OnItemClickListener { parent, view, position, id ->
    // Do something in response to the click.
}

Java

// Create a message handling object as an anonymous class.
private OnItemClickListener messageClickedHandler = new OnItemClickListener() {
    public void onItemClick(AdapterView parent, View v, int position, long id) {
        // Do something in response to the click.
    }
};

listView.setOnItemClickListener(messageClickedHandler);
