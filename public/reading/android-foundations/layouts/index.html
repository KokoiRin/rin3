布局定义了应用中用户界面的结构，例如 Activity 中的界面。布局中的所有元素都使用 View 和 ViewGroup 对象的层次结构构建。View 通常会绘制用户可以看到并与之交互的内容。ViewGroup 是一个不可见的容器，负责定义 View 和其他 ViewGroup 对象的布局结构，如图 1 所示。

View 对象通常称为控件，可以是许多子类之一，例如 Button 或 TextView。ViewGroup 对象通常称为布局，可以是提供不同布局结构的多种类型之一，例如 LinearLayout 或 ConstraintLayout。

可以通过两种方式声明布局：

  • 在 XML 中声明 UI 元素。Android 提供了一套直观的 XML 词汇，与控件和布局等 View 类及其子类相对应。也可以使用 Android Studio 的布局编辑器，通过拖放界面构建 XML 布局。
  • 在运行时实例化布局元素。应用可以创建 View 和 ViewGroup 对象，并以编程方式操作它们的属性。

在 XML 中声明 UI，可以将应用的呈现方式与控制其行为的代码分离。使用 XML 文件也更容易为不同屏幕尺寸和方向提供不同布局。支持不同屏幕尺寸中对此有进一步讨论。

Android 框架允许灵活地选择其中任意一种方式，或同时使用两种方式构建应用 UI。例如，可以在 XML 中声明应用的默认布局，然后在运行时修改布局。

提示：要在运行时调试布局，请使用布局检查器工具。

编写 XML

使用 Android 的 XML 词汇，可以快速设计 UI 布局及其包含的屏幕元素，就像使用一系列嵌套元素在 HTML 中创建网页一样。

每个布局文件必须恰好包含一个根元素，它必须是 View 或 ViewGroup 对象。定义根元素后，可以添加额外的布局对象或控件作为子元素，逐步构建定义布局的 View 层次结构。例如，以下 XML 布局使用垂直的 LinearLayout 容纳一个 TextView 和一个 Button：

<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
              android:layout_width="match_parent"
              android:layout_height="match_parent"
              android:orientation="vertical" >
    <TextView android:id="@+id/text"
              android:layout_width="wrap_content"
              android:layout_height="wrap_content"
              android:text="Hello, I am a TextView" />
    <Button android:id="@+id/button"
            android:layout_width="wrap_content"
            android:layout_height="wrap_content"
            android:text="Hello, I am a Button" />
</LinearLayout>

在 XML 中声明布局后，将文件以 .xml 扩展名保存到 Android 项目的 res/layout/ 目录中，以便正确编译。

有关布局 XML 文件语法的更多信息，请参阅布局资源。

加载 XML 资源

编译应用时，每个 XML 布局文件都会被编译成一个 View 资源。在应用的 Activity.onCreate() 回调实现中加载布局资源。具体做法是调用 setContentView()，以 R.layout.layout_file_name 的形式传入布局资源的引用。例如，如果 XML 布局保存为 main_layout.xml，则按如下方式为 Activity 加载它：

Kotlin

fun onCreate(savedInstanceState: Bundle) {
    super.onCreate(savedInstanceState)
    setContentView(R.layout.main_layout)
}

Java

public void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    setContentView(R.layout.main_layout);
}

Activity 启动时，Android 框架会调用其中的 onCreate() 回调方法。有关 Activity 生命周期的更多信息，请参阅 Activity 简介。

属性

每个 View 和 ViewGroup 对象都支持各自的一组 XML 属性。有些属性是某个 View 对象特有的。例如，TextView 支持 textSize 属性。不过，继承此类的任何 View 对象也会继承这些属性。有些属性是所有 View 对象共有的，因为它们从根 View 类继承而来，例如 id 属性。其他属性称为布局参数，它们由对象的父 ViewGroup 对象定义，用于描述 View 对象的某些布局安排。

ID

任何 View 对象都可以关联一个整数 ID，以便在树中唯一标识该 View。应用编译后，此 ID 作为整数引用，但通常是在布局 XML 文件中，将它作为字符串赋给 id 属性。这是所有 View 对象共有的 XML 属性，由 View 类定义。你会经常使用它。XML 标签中 ID 的语法如下：

android:id="@+id/my_button"

字符串开头的 at 符号（@）表示 XML 解析器会解析并展开 ID 字符串的剩余部分，将其识别为 ID 资源。加号（+）表示这是一个新的资源名称，必须创建并添加到 R.java 文件中的资源里。

Android 框架还提供了许多其他 ID 资源。引用 Android 资源 ID 时，不需要加号，但必须按如下方式添加 android 包命名空间：

android:id="@android:id/empty"

android 包命名空间表明你引用的是 android.R 资源类中的 ID，而不是本地资源类中的 ID。

要创建 View 并从应用中引用它们，可以采用以下常见模式：

  1. 在布局文件中定义一个 View，并为其分配唯一 ID，如以下示例所示：
    <Button android:id="@+id/my_button"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="@string/my_button_text"/>
  2. 创建 View 对象的实例，并从布局中获取它，通常在 onCreate() 方法中进行，如以下示例所示：

    Kotlin

    val myButton: Button = findViewById(R.id.my_button)

    Java

    Button myButton = (Button) findViewById(R.id.my_button);

创建 RelativeLayout 时，为 View 对象定义 ID 非常重要。在相对布局中，同级 View 可以定义相对于另一个同级 View 的布局，后者通过唯一 ID 引用。

ID 不必在整棵树中唯一，但必须在你搜索的那部分树中唯一。搜索范围往往可能是整棵树，因此最好尽可能保证 ID 唯一。

布局参数

名为 layout_something 的 XML 布局属性，为 View 定义适用于其所在 ViewGroup 的布局参数。

每个 ViewGroup 类都实现了一个继承 ViewGroup.LayoutParams 的嵌套类。该子类包含一些属性类型，用来以适合该 ViewGroup 的方式定义每个子 View 的大小和位置。如图 2 所示，父 ViewGroup 为每个子 View 定义布局参数，其中也包括子 ViewGroup。

每个 LayoutParams 子类都有自己的值设置语法。每个子元素都必须定义适用于其父元素的 LayoutParams，不过它也可以为自己的子元素定义另一种 LayoutParams。

所有 ViewGroup 都包含通过 layout_width 和 layout_height 指定的宽度和高度，每个 View 都必须定义这两项。许多 LayoutParams 还包含可选的外边距和边框。

可以使用精确的测量值指定宽度和高度，但你可能不希望经常这样做。更常见的做法是使用以下常量之一设置宽度或高度：

  • wrap_content：让 View 将自身大小设置为其内容所需的尺寸。
  • match_parent：让 View 尽可能扩展到父 ViewGroup 所允许的大小。

通常，我们不建议使用像素等绝对单位指定布局宽度和高度。更好的方式是使用相对测量值，例如密度无关像素单位（dp）、wrap_content 或 match_parent，因为这有助于应用在多种设备屏幕尺寸上正确显示。可接受的测量类型在布局资源中定义。

布局位置

View 具有矩形几何形状。它的位置由一对左侧和顶部坐标表示，两个尺寸则由宽度和高度表示。位置和尺寸的单位都是像素。

可以调用 getLeft() 和 getTop() 获取 View 的位置。前者返回表示 View 的矩形的左侧（x）坐标，后者返回顶部（y）坐标。这些方法返回的是 View 相对于父级的位置。例如，getLeft() 返回 20，表示该 View 位于其直接父级左边缘右侧 20 像素处。

此外，还有一些便捷方法可避免不必要的计算，即 getRight() 和 getBottom()。它们返回表示 View 的矩形的右边缘和底边缘坐标。例如，调用 getRight() 相当于计算 getLeft() + getWidth()。

尺寸、内边距和外边距

View 的尺寸用宽度和高度表示。每个 View 有两对宽高值。

第一对称为测量宽度和测量高度。它们定义 View 希望在父级中占据的大小。可以调用 getMeasuredWidth() 和 getMeasuredHeight() 获取测量尺寸。

第二对称为宽度和高度，有时也称为绘制宽度和绘制高度。它们定义布局完成后、绘制时 View 在屏幕上的实际尺寸。这些值可能与测量宽高不同，但不一定不同。可以调用 getWidth() 和 getHeight() 获取宽度和高度。

测量尺寸时，View 会考虑内边距。内边距分别以像素表示 View 左、上、右、下各侧的留白。可以使用内边距将 View 的内容偏移指定像素数。例如，左内边距为 2 会将内容推到左边缘右侧 2 像素处。可以使用 setPadding(int, int, int, int) 设置内边距，并调用 getPaddingLeft()、getPaddingTop()、getPaddingRight() 和 getPaddingBottom() 查询。

虽然 View 可以定义内边距，但不支持外边距。不过，ViewGroup 支持外边距。详情请参阅 ViewGroup 和 ViewGroup.MarginLayoutParams。

有关尺寸的更多信息，请参阅尺寸。

除了以编程方式设置外边距和内边距，也可以在 XML 布局中设置，如以下示例所示：

  <?xml version="1.0" encoding="utf-8"?>
  <LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
                android:layout_width="match_parent"
                android:layout_height="match_parent"
                android:orientation="vertical" >
      <TextView android:id="@+id/text"
                android:layout_width="wrap_content"
                android:layout_height="wrap_content"
                android:layout_margin="16dp"
                android:padding="8dp"
                android:text="Hello, I am a TextView" />
      <Button android:id="@+id/button"
              android:layout_width="wrap_content"
              android:layout_height="wrap_content"
              android:layout_marginTop="16dp"
              android:paddingBottom="4dp"
              android:paddingEnd="8dp"
              android:paddingStart="8dp"
              android:paddingTop="4dp"
              android:text="Hello, I am a Button" />
  </LinearLayout>

前面的示例展示了外边距和内边距的应用。TextView 四周使用相同的外边距和内边距，Button 则展示了如何分别对不同边缘设置它们。

注意：建议使用 paddingStart、paddingEnd、layout_marginStart 和 layout_marginEnd，代替 paddingLeft、paddingRight、layout_marginLeft 和 layout_marginRight，因为前者能更好地同时适配从左到右和从右到左书写的语言。

构建动态列表

如果布局内容是动态的或无法预先确定，可以使用 RecyclerView 或 AdapterView 的子类。通常 RecyclerView 是更好的选择，因为其内存使用比 AdapterView 更高效。

为适配器视图填充数据

可以将 AdapterView 实例（例如 ListView 或 GridView）绑定到 Adapter，从而填充该视图。适配器从外部来源获取数据，并创建表示各数据项的 View。

Android 提供多个 Adapter 子类，可用于获取不同类型的数据，并为 AdapterView 构建 View。最常见的两种适配器是：

ArrayAdapter
数据源为数组时使用此适配器。默认情况下，ArrayAdapter 对每个数组项调用 toString()，并将结果放入 TextView，以此为每个数组项创建 View。

例如，要在 ListView 中显示一个字符串数组，可以使用构造器指定每个字符串的布局以及字符串数组，初始化新的 ArrayAdapter：

Kotlin

    val adapter = ArrayAdapter<String>(this, android.R.layout.simple_list_item_1, myStringArray)

Java

    ArrayAdapter<String> adapter = new ArrayAdapter<String>(this,
            android.R.layout.simple_list_item_1, myStringArray);

此构造器的参数如下：

  • 应用的 Context
  • 包含一个用于显示数组中每个字符串的 TextView 的布局
  • 字符串数组

然后在 ListView 上调用 setAdapter()：

Kotlin

    val listView: ListView = findViewById(R.id.listview)
    listView.adapter = adapter

Java

    ListView listView = (ListView) findViewById(R.id.listview);
    listView.setAdapter(adapter);

要自定义各项的外观，可以重写数组中对象的 toString() 方法。或者，如果希望为各项创建的 View 不是 TextView，例如希望每个数组项都对应一个 ImageView，可以扩展 ArrayAdapter 类，并重写 getView()，为各项返回所需类型的 View。

SimpleCursorAdapter
数据来自 Cursor 时使用此适配器。使用 SimpleCursorAdapter 时，应指定 Cursor 中每一行使用的布局，以及希望将 Cursor 的哪些列插入布局的哪些 View。例如，要创建包含姓名和电话号码的列表，可以执行一个查询，返回的 Cursor 中每个人对应一行，姓名和号码分别对应不同的列。然后创建一个字符串数组，指定每个结果布局应使用 Cursor 中的哪些列；再创建一个整数数组，指定每列应放入的对应 View：

Kotlin

    val fromColumns = arrayOf(ContactsContract.Data.DISPLAY_NAME,
                              ContactsContract.CommonDataKinds.Phone.NUMBER)
    val toViews = intArrayOf(R.id.display_name, R.id.phone_number)

Java

    String[] fromColumns = {ContactsContract.Data.DISPLAY_NAME,
                            ContactsContract.CommonDataKinds.Phone.NUMBER};
    int[] toViews = {R.id.display_name, R.id.phone_number};

实例化 SimpleCursorAdapter 时，传入每个结果使用的布局、包含结果的 Cursor，以及这两个数组：

Kotlin

    val adapter = SimpleCursorAdapter(this,
            R.layout.person_name_and_number, cursor, fromColumns, toViews, 0)
    val listView = getListView()
    listView.adapter = adapter

Java

    SimpleCursorAdapter adapter = new SimpleCursorAdapter(this,
            R.layout.person_name_and_number, cursor, fromColumns, toViews, 0);
    ListView listView = getListView();
    listView.setAdapter(adapter);

随后，SimpleCursorAdapter 使用提供的布局，为 Cursor 中的每一行创建 View，将每个 fromColumns 项插入对应的 toViews View。

如果在应用运行期间更改了适配器读取的底层数据，请调用 notifyDataSetChanged()。它会通知关联的 View 数据已更改，View 将自行刷新。

处理点击事件

可以实现 AdapterView.OnItemClickListener 接口，响应 AdapterView 中各项的点击事件。例如：

Kotlin

listView.onItemClickListener = AdapterView.OnItemClickListener { parent, view, position, id ->
    // Do something in response to the click.
}

Java

// Create a message handling object as an anonymous class.
private OnItemClickListener messageClickedHandler = new OnItemClickListener() {
    public void onItemClick(AdapterView parent, View v, int position, long id) {
        // Do something in response to the click.
    }
};

listView.setOnItemClickListener(messageClickedHandler);
